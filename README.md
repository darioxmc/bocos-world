# Boco's World

A browser revival of an old assembly-language class project.

Open `index.html` directly or serve the folder with any static web server.

## Play Online

- [Boco's World: original revival](https://darioxmc.github.io/bocos-world/)
- [Boco's World: Skybound](https://darioxmc.github.io/bocos-world/skybound/),
  a separate 16-bit-inspired platformer with touch controls and three save slots.

Skybound's source and local development instructions are in `skybound/`.
