# Integration contracts

Separate static game. No changes to ../bocos-world. Logical viewport 320x240, TILE=16, Boco display 32x32, Phaser Arcade fixed-step at 60 Hz. ES modules imported by game.js. Phaser global from vendor/phaser.min.js. Main gameplay scene key Play.

## art.js (art worker)
export function createArt(scene). Generate pixel textures using CanvasTexture (no smoothing) with keys boco-idle, boco-run0..5, boco-jump, boco-fall, boco-glide0..1, boco-duck, boco-peck, boco-swipe, boco-hurt, boco-win (all 32x32, default facing right, feet baseline y=31). Enemies: beetle, shellback, hopper, plant, bird, moth, seed (32x32 except seed 8x8). Bosses: boss-beetle, boss-moth, boss-plant, boss-bird (64x64). Objects: flower, emblem, checkpoint, exit (16x32), gust (16x16). Tiles: meadow-ground, meadow-fill, cliff-ground, cliff-fill, canopy-ground, canopy-fill, roost-ground, roost-fill (16x16), platform (32x8). export function createBackdrop(scene, areaKey, worldWidth, worldHeight) returning {update(camera,time), destroy()}; layer depths <0, fixedScrollFactor for parallax where appropriate. Texture ownership only.

## levels.js (level worker)
export const LEVELS array of 4 area definitions. Each: {id:'meadow'|'cliff'|'canopy'|'roost',name,subtitle,width,height,spawn:{x,y},terrain:[{x,y,w,h}],platforms:[{x,y,w,h,oneWay?:true,move?:{axis:'x'|'y',distance,speed}}],enemies:[{id,type:'beetle'|'shellback'|'hopper'|'plant'|'bird'|'moth',x,y,range?:number}],flowers:[{id,x,y}],emblems:[{id,x,y}],checkpoints:[{id,x,y}],gusts:[{x,y,w,h}],boss:{type:'beetle'|'moth'|'plant'|'bird',name,x,y,arena:{x,y,w,h}},exit:{x,y}}. Coordinates in world pixels, all entity x/y mean FEET / bottom-center except gusts/rectangles upper-left. Terrain rectangles are solid; static ledges use platforms with oneWay true. Baseline floor ~208, world height can grow for cliffs but no mandatory blind falls. 3 substantial handcrafted areas ~5000-7000px each, optional roost ~2000px. Include checkpoints before boss, collectible detours, fair jumps (horizontal range ~120px at speed115, jump=-280 gravity800; gliding fall cap55 permits longer gaps). No imports/dependencies.

## input.js + UI shell (UI worker)
export class InputController: constructor(), bind() (idempotent), update() called once/frame, down(action), pressed(action) (edge maintained until next update), clear(), destroy(); actions left,right,up,down,jump,attack,glide,pause,confirm,back. Game will call update only in Phaser scene update. Shell/menu navigation may have separate handler, but must not consume gameplay edges. Keyboard Space/W/Up jump, Z/J attack, X/K glide, Enter/Escape pause; gamepad remap and physical keys settings persisted via settings or own key. Touch dpad sliding pointer + multi-pointer action aggregation; controller disconnect/blur emits window event skybound:pause. document #game-mount and #overlay. export class Shell from shell.js constructor({onStart(slot,levelIndex),onResume(),onRestart(),onExit(),onSettings(settings)}); showTitle(),showSlots(),showPause(),showWorld(slot),showVictory(slot,levelIndex,isFinal),showEnding(slot),hide(),updateHud({area,health,maxHealth,emblems,bossName,bossHealth,bossMax,gliding}),showToast(text). UI takes SaveStore dependency directly. User can choose imported saves and fresh New Game via slot selection. Shell settings UI includes assists, volume, touch size/visibility. main sets callbacks; onStart uses slot index 0..2 and optional levelIndex; Shell doesn't assume global game internals. window.dispatchEvent CustomEvent('skybound:settings',{detail:settings}) for preferences if needed.

## saves.js + audio.js (services worker)
export const SaveStore singleton with slots() => three entries (null or slot object), get(index), create(index) => slot, save(index,patch) => slot, delete(index), export(index)=>JSON string, import(index,json)=>slot, getSettings(), saveSettings(patch). Slot schema {version:1,name,area:0,checkpoint:null,health:3,defeated:[],emblems:[],playtime:0,completed:false,assists:{extraHealth:false,reducedDamage:false,toggleGlide:false},updatedAt}. Area 0..3. Defeated boss IDs strings ('meadow', etc). save only changes specified fields. Validate indices, enums, bounds, corrupt JSON, blocked storage; preserve in-memory fallback and surface storage availability. Replaying completed area won't regress unlocked area. Settings {music:0.35,effects:0.6,muted:false,touchScale:1,touchMode:'auto',bindings:{},padBindings:{}}. Export class AudioEngine constructor(), unlock(), effect(name), setSettings(settings), startMusic(area), stopMusic(), pause(), resume(), destroy(). Effects jump,glide,peck,hit,flower,checkpoint,boss,win,menu. Web Audio retro synthesis, short original looping music, bounded concurrency, no unbounded audio queue. Save/audio don't reference gameplay.

Workers own only their assigned files; use apply_patch and list changed files on completion. Main owns game.js, tools/, tests/, package.json, documentation. Coordinate interface changes with main.
